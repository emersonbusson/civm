# Documentation

English is the canonical language for public and operational documentation.
Brazilian Portuguese translations use the `.pt-BR.md` suffix and link back to
their English source. The root [README](../README.md) is the project overview;
the [Portuguese README](../README.pt-BR.md) is its secondary translation.

## Architecture and specifications

The `docs/specs/` tree contains design records and historical implementation
specifications. They retain the language in which they were written until a
substantive review; use the project README and operating guides for current
behavior.
